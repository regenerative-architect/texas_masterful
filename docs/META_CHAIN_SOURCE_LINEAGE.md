# Meta-Chain source lineage

The v2.4 Meta-Chain Orchestrator was merged from two project lineages:

1. **Texas Master Systems OS v2.3.1 Adaptive Planner**, which provides the ten-domain data model, Evidence Ledger, Project Commons, Cross-Domain Nexus, Cascade Lab, resilient WebLLM/PWA delivery, IndexedDB records, Trystero/WebRTC collaboration, quests and deterministic planning fallbacks.
2. The prior **Wizard Scroll: Deweaponization / Meta-Prompt Chain** artifact located in the project Library. Its Empowerment Chain Architecture supplied the source-derived `Empowerment & Collaborative Intelligence` template: Awareness, Redesign, Structural Empowerment, Epistemic Sovereignty and AI-Augmented Collaborative Intelligence.

The source-derived template is integrated as an executable chain rather than reproducing the entire prior page. The broader chain families are new orchestration templates tailored to the Texas systems-of-systems data model.
