# Gamified Collaboration

The v2.1 collaboration layer uses optional quests, XP, levels and badges as coordination scaffolding. Core features are never gated by gamification.

## XP design

XP is derived from useful work: projects, completed tasks, evidence entries, decision records, resolved questions, accepted handoffs and completed quests. Comment XP is capped to reduce message-spam incentives.

## Principles

- Reward closure, evidence and successful handoffs more than chatter.
- Do not interpret XP as competence, identity, authority or professional standing.
- Keep quests cooperative and tied to measurable acceptance conditions.
- Allow users to ignore gamification without losing functionality.
- Keep shared quest records subject to the same P2P privacy boundary as other collaboration records.
