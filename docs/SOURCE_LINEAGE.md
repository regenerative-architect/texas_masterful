## Important reconstruction boundary

The Project library exposed these archives as indexed resources, but the raw ZIP bytes were not authorized for extraction in this build session. The master therefore does **not** claim to be a byte-for-byte merge of those archives. It is a clean unified implementation reconstructed from their newest indexed specifications, README/build-report features, accessible standalone lineage, and current upstream dependency documentation.

This choice preserves provenance honesty and prevents hidden copy/merge assumptions.
